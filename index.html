Part B

System Structure Evaluation

Card 1

Likely Kernel Structure

This system is likely using a hybrid kernel because it needs both performance and modularity. A cloud-based university management system handles scheduling, I/O, multiprocessing, and kernel-level threading.

Card 2

Kernel-Level Threads

Kernel-level threads allow the operating system to schedule threads directly across CPU cores. If one thread blocks for I/O, other threads can continue running.

Part C

Bottleneck Analysis

Bottleneck 1

CPU Starvation

Low-priority processes may wait too long if high-priority processes keep entering the ready queue.

Bottleneck 2

I/O Delay

Database backup can slow down storage access and affect other services that depend on disk operations.

Bottleneck 3

Context Switching Overhead

Frequent process changes waste CPU time because the system must save and restore process states.

Part D

Critical Thinking

Scenario

If P3 Becomes CPU-Intensive

P3 will dominate CPU execution because it has the highest priority.

Impact

Reduced Fairness

Other processes may experience long waiting times, lower throughput, and possible starvation.

Solution

Control CPU Usage

Aging, priority adjustment, and CPU usage limits can reduce starvation and improve fairness.
