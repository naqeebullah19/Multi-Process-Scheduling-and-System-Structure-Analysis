Part B

System Structure Evaluation

Likely Kernel Structure

Hybrid Kernel

A hybrid kernel is suitable because the system needs strong performance for process scheduling, I/O handling, multiprocessing, and kernel-level threading, while still keeping the design modular.

Threading Model

Kernel-Level Threads

Kernel-level threads allow the operating system to schedule threads across CPU cores. If one thread blocks for I/O, other threads can continue execution.

Part C

Performance and Bottleneck Analysis

Bottleneck 1

CPU Starvation

Low-priority processes may wait too long if high-priority processes keep using the CPU.

Bottleneck 2

I/O Delay

Database backup can slow down disk operations and affect services that depend on storage.

Bottleneck 3

Context Switching Overhead

Frequent switching wastes CPU time because process states must be saved and restored.

Part D

Critical Thinking Scenario

Scenario

P3 Becomes CPU-Intensive

P3 will dominate execution because it has the highest priority in the scheduling order.

Impact

Reduced Fairness

Lower-priority processes may experience longer waiting time, lower throughput, and starvation.

Improvement

Aging and Priority Control

Aging, priority adjustment, and CPU usage limits can improve fairness and responsiveness.
