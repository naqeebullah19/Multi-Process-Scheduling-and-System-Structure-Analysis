Part B

System Structure Evaluation

Likely Kernel Structure

The system is most likely using a hybrid kernel. A cloud-based university management system needs performance for process scheduling, I/O handling, multiprocessing, and kernel-level threading, but it also benefits from modular design and stability.

A purely microkernel design may add communication overhead, while a monolithic kernel may be less modular. A hybrid kernel gives a practical balance between performance and maintainability.

Kernel-Level Threads

Kernel-level threads improve performance because the operating system can schedule each thread directly across multiple CPU cores. If one thread blocks for I/O, other threads of the same process can continue running.

This is better than user-level threads in this environment because user-level threads can block the whole process when one thread makes a blocking system call.

Part C

Performance and Bottleneck Analysis

Potential Bottlenecks

  • CPU starvation: Low-priority processes such as P2 may wait for a long time.
  • I/O delay: The database backup process can slow down storage and disk access.
  • Context switching overhead: Frequent switching wastes CPU time.

Suggested Improvements

  • Aging: Gradually increase the priority of waiting processes to reduce starvation.
  • Better I/O scheduling: Run backup tasks during low-load periods.
  • Load balancing: Distribute threads across multiple CPU cores.

Part D

Critical Thinking: If P3 Becomes CPU-Intensive

If P3 becomes CPU-intensive, it will dominate the CPU because it has the highest priority. This will reduce scheduling fairness because lower-priority processes like P1, P4, and P2 will get less CPU time.

System responsiveness may initially seem good for attendance tracking, but other services will slow down. Report generation, backups, and registration tasks may experience longer waiting times.

Overall throughput can also decrease because the CPU may spend too much time on one high-priority task, causing the rest of the system to progress slowly. Aging, priority adjustment, or limiting continuous CPU usage by high-priority processes can help solve this issue.
